# 京张共长线两轮整合改进计划

本计划将“达到精选候选所需的实质深化”和“形成完整双语专业交付”合并实施。所有成果以公开资料、方案研究边界和可复算数据为依据；未经现场调查、权属核验或专项审查的内容保持为建议值、拟定机制或未知项。

## 成果组织原则

1. 五张固定评审主图优先承载空间结构、片区深度、交通蓝绿和指标证据，不以效果图替代技术表达。
2. 效果图用于说明空间气质，每张图均与面积、界面、控制值或实施条件并列。
3. 所有数字标记为“公开事实”“复算值”“建议目标”或“未知”；建议目标不使用完成态进度条。
4. 每项 AI 服务均须提供人工或非数字等价路径。责任主体、接管方式、申诉渠道和退出条件同步公布。
5. 正文同一论断最多保留三项证据标记，完整证据关系进入结构化矩阵。

- 中文与英文主要交付物逐项对应。

- 十二项 AI 场景通过规则校验，全部负向测试被预期规则拦截。

- 自检、来源、空间、视觉和本地提交校验全部通过。
