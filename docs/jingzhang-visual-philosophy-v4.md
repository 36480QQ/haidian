# 轨迹证据：京张共长线视觉体系 v4

本版以“轨迹证据”为核心视觉观念。京张铁路的线性基础设施、百年城市演变与当代公共服务被组织为一条可阅读、可复核的空间轨迹。图件首先回答范围、尺度、关系和责任，再通过少量效果图呈现场所气质。地图、图表与剖面承担证据表达，效果图承担空间想象，二者在版面中保持清晰分工。

总平图采用真实 GeoJSON 图层和统一投影，沿场地长轴旋转排布，以适应 A3 横向评审页面并减少无效留白。用地、蓝绿、慢行、建筑、重点片区和服务节点保留独立图层语义，所有数字直接来自提交包的结构化数据。地图不模拟法定规划图，不使用未经确认的地块、权属或红线信息；示意范围通过图例、注记和证据状态明确标识。

版式遵循城市设计投标文本常见的编辑网格：标题区简洁，主体区以一张主图统领，辅助图表用于解释尺度、指标和实施条件。页面避免空置卡片和装饰性框线，信息密度通过地图、矩阵、甘特图、比较图和紧凑注释提升。每页只保留一个视觉主角，其余信息按证据层级退后，形成远观可识别、近读可核验的阅读秩序。

色彩来自“京张共长线”品牌系统：轨道墨蓝用于结构和文本，叶绿用于生态与公共空间，市民青用于慢行和信息流，公共橙用于责任、停止和服务提示，审查金用于门控与待决条件。纸张底色维持温和米白，减少长时间评审的视觉疲劳；强调色严格对应信息类别，不作无语义装饰。

空间效果图控制在三张以内，分别用于共享公共空间、典型慢行断面和公共服务节点。它们与技术图并置，并由尺度、构造、运营和验收信息约束，使氛围表达服务于设计判断。人物、材料和种植仅表达设计意向，不被当作已建成事实；工程尺度与实施条件仍以结构化数据和专业审查为准。

最终成果通过 GeoPandas、Matplotlib、NetworkX 和 ReportLab 的命令行工作流生成 PNG 与 PDF，不输出手工绘制 SVG。所有中英文图件保持相同图序、数值、空间范围和证据边界，并在生成后逐页渲染检查文字、裁切、图例、图片清晰度和页面密度。
