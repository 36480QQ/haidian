# 京张横街 / Jingzhang Cross-Streets

## 一页评审摘要

方案把43.6平方公里理解为一张城市网络，而不是一条纵向品牌带：京张公园承担南北公共骨架，清河与小月河承担蓝绿边界，清河水岸、林大北路、清华东路、成府路、知春路、北三环、学院南路与西直门外大街八条真实横街承担校园—园区—社区—站口—水岸之间的横向连接。

11.4平方公里总体设计沿真实横街、公园曲线和水岸形成完整、非等宽的概念用地拓扑；三类有量纲剖面分别控制水岸研发、近校转换和四象限站城。众智园、AI原点与大钟寺进入OSM街坊底图、首层改造、条件体量、公众/后勤流线、日常/事件状态和首批项目，不用三座雕塑替代城市设计。

15项项目按公共空间、合作租赁、法定工程三类权限实施。12张场景卡逐卡给出房间、频次/容量、验收和停止触发。正式GIS、地块权属、FAR、高度、市政与工程资料仍待补齐，但它们触发整链替换，不构成停止设计的理由。完整叙事见 `proposal.md` / `proposal.en.md`；五张双语图、18页A3、4张A0、九类GeoJSON、指标、来源、假设和逐项矩阵使用同一编号。
