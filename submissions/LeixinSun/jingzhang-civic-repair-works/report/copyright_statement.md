# 版权、生成方法与复用边界

本投稿由 GitHub 用户 LeixinSun 通过 Codex 组织公开资料、编写文本、生成结构化数据与确定性图件。投稿许可采用 `COMMUNITY-DISPLAY-ONLY`，适用范围以本项目仓库和征集规则为准。

五张中文图、五张英文图、离线网页和 A3/A0 图纸均由本投稿的 GeoJSON、`metrics.json` 与矩阵文件确定性生成；PNG 使用 Matplotlib 绘制，PDF 使用 ReportLab 排版。它们未使用商业地图瓦片、遥感截图、新闻图片、第三方人物肖像、企业商标或外部字体文件；本机 Arial Unicode 字体仅在生成 PDF/PNG 时用于字形呈现，不随包分发。图面中的边界、重点区、建筑模块、道路和公共空间均按正文标注为临时约束或概念建议。

外部案例仅作研究参照。法国指数、CTI、企业流程和国际组织统计均以独立文字和自建图形转述，不复制官方标识、图表或受保护版式。Caterpillar 页面在自动访问环境中受限，相关表述仅保守概括公开的再制造工序。WBCSD CTI v4 的 CC BY-ND 4.0 条款被记录为“可释义、不得改编原图”。

本包未提交 AI 生成人物或现场效果图，也未提交或写入任何 API 凭据。可选概念封面曾通过外部 OpenAI 兼容图像接口尝试生成，但接口返回用户额度不足，未产生图像资产，因此网站继续使用仓库默认封面。任何后续新增图像、视频、音频或三维资产都必须单独登记工具、提示、来源、授权、合成状态和限制。
