Twelve-week controlled pilot

Six two-week windows produce evidence and apply stop rules. Failed access control, inaccessible ordinary service or unresolved responsibility prevents progression.

Weeks 01–02

Lock baseline

Issue list, data boundary, responsible roles and ordinary service.

Pause without accountable ownership
Weeks 03–04

Desktop replay

Public, synthetic or authorised de-identified data.

Return if results cannot be reproduced
Weeks 05–06

Failure injection

Access breach, error, conflict and stop drills.

Terminate if the system cannot stop
Weeks 07–08

Public walkthrough

Plain language, accessibility and staffed routes.

Pause if equivalent service is inaccessible
Weeks 09–10

Coordinate recovery

Joint review, challenge, correction receipt and recovery.

Retain human workflow if conflict remains
Weeks 11–12

Independent review

Continue, remediate or exit with a public summary.
