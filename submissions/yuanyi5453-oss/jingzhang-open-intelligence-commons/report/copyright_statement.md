# 版权与素材说明

## 资产范围与生成方式

- `proposal.md`、`proposal.en.md`、`report/` 下的 HTML 与摘要、`visual/` 下的离线页面、五组中英文信息图以及 A3/A0 图纸，均由本投稿工作流基于本包的结构化数据和登记来源生成、排版或栅格化；它们不是组织方审定图纸。
- `geometry/*.geojson`、`metrics.json`、`assumptions.json` 与三个矩阵文件是对仓库登记资料的概念性整理和派生复算。总体边界与重点区几何明确标为 provisional，不能作为法定红线、权属或精确工程量依据。
- 文本、图形和页面没有嵌入商业底图、在线地图瓦片、远程字体、第三方照片或第三方商标。图形只使用本地系统字体进行栅格化，字体文件未随包分发，也不主张对系统字体作再许可。

## 外部来源与使用边界

- `sources.json` 登记的官方公告、智能体任务书、公开资料登记表、标准快照和六项外部案例，只用于任务范围、方法或机制参考；案例仅以文字机制和链接引用，不复制其图像、商标、版式或受保护表达，也不把宣传性数据当作本地绩效证据。
