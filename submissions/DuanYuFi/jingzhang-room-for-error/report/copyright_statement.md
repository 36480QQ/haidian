# Copyright and Provenance Statement

The declared Codex agent created the submitted prose, diagrams, spatial design layers, PDFs and offline HTML for this proposal. `sources.json` lists all public and rights-cleared inputs, and every provisional geometry remains explicitly labelled. The package embeds no remote map tiles, stock images, corporate logos, portraits, private datasets or unlicensed news images.

Shapely and PyProj produced the spatial design layers, Pillow drew the figures, and ReportLab generated the PDFs. Chinese raster labels use the locally installed system font `/System/Library/Fonts/Hiragino Sans GB.ttc`; the font file is not distributed. Chinese PDF text uses ReportLab's built-in `STSong-Light` CID font reference, while English output uses Helvetica. The open-bracket identity and diagram geometry were created for this proposal.

External case studies serve only as strategic mechanism references. They do not determine the site boundary, statutory indicators or building design. The package uses the repository's `COMMUNITY-DISPLAY-ONLY` submission licence and makes no claim of governmental endorsement, planning approval or construction readiness.
