## Embedded font

The four offline HTML pages (`report/proposal.html`, `report/proposal.en.html`, `visual/index.html`, `visual/index.en.html`) embed a subset of **Noto Sans SC** (Regular weight) as a base64 woff2 data URI (`@font-face`, `font-family: 'TrifoldSC'`) so CJK text renders on machines without Chinese fonts.

- Source: https://github.com/notofonts/noto-cjk/raw/main/Sans/OTF/SimplifiedChinese/NotoSansCJKsc-Regular.otf (fetched 2026-08-25); source file kept at `build/fonts/NotoSansCJKsc-Regular.otf`, outside the package.
- License: SIL Open Font License 1.1 (OFL-1.1) — embedding and redistribution of the font (including subsets) are permitted; the copyright and license notice is preserved in the embedded font's name table. No OFL Reserved Font Name is declared for Noto.
- Subsetting: `build/embed_font.py` (fonttools) subsets the font to the characters actually used by the four pages plus ASCII printable and common fullwidth punctuation (1204 characters, 2017 glyphs, ~366 KB woff2), then injects it idempotently into each page's inline `<style>`.
