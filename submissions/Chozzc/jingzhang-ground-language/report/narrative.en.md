# JING-ZHANG GROUND LANGUAGE Deliverable Narrative

This package is organised around one proposition: people, disabled users and robots from different vendors should read the same public-ground state. A six-word grammar, three-field/two-wing validation chain, twelve scenarios, eight user groups and a reversible pilot share one structured evidence model. `proposal.en.md` is the authoritative English narrative; geometry, metrics, professional matrices, the A3 booklet, A0 boards and offline website provide cross-checkable representations.

Every spatial location and quantity is limited by `assumptions.json`. Provisional geometry supports concept generation and content review only. Any field pilot must wait for official data, site permission, user co-design and multidisciplinary safety review.
