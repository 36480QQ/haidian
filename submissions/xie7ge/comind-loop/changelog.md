# 方案迭代记录

## v2.0 - 2026-08-13

This update responds to the 70/100 repository-intake review of PR #1432 by deepening one original mechanism across prose, space, governance, metrics and drawings. No peer visual, geometry, text or branded concept is copied.

- Named the original mechanism **CoMind Translation Protocol (CTP)** and defined six lifecycle stages: INTAKE, PARSE, COMPILE, PILOT, RETURN, and RETIRE / RENEW.
- Added an eight-field **Urban Translation Receipt** for each of the twelve scenario nodes.
- Added five public translation rights: intelligibility, equivalent choice, correction, local pause, and public return.
- Recast the three key areas as responsibility parsing, open compilation, and urban pilot-translation stations.
- Required a distinct public return, pause trigger and fallback mode for every scenario in `geometry/constraints.geojson`.
- Added five auditable CTP metrics to `metrics.json`.
- Added `risk.json` with eight validated risk dimensions, triggers, actor types, mitigations, human review and stop conditions.
- Reworked bilingual narrative, figures, A3 booklet, A0 boards and visual index so the same protocol is visible at every scale.

All geometry remains provisional and conceptual. The update does not claim official boundaries, approval, implementation or government endorsement.
