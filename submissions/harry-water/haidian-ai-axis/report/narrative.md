# 评审导读｜海淀新轴

本导读对应 `proposal.md` 与 `proposal.en.md` 的当前参赛包。建议先读第一、三、六、十一章，再查看五对双语图件、A3 册页与 A0 展板；机器可读事实以 `sources.json`、九个 `geometry/*.geojson`、`metrics.json`、`assumptions.json` 和三份对应矩阵为准。

## 1. 一条主线

全文沿一条闭合链展开：**遗产主线 → 三站分工 → 两翼供给／反馈 → 六类空间原型 → 十个运行场景 → 一套年度账本**。

核心命题是“**海淀新轴：百年京张，从运煤到运算**”：把京张铁路历史上的区域交换功能，转译为面向 AI 时代的城市公共空间、科研创新与双城算力协同。`海淀新轴` 与英文品牌 `HAIDIAN AI AXIS` 为等义品牌，不主张它是法定规划轴线、北京中轴线延长线或世界遗产关联项目。

## 2. 需要同时阅读的事实边界

1. 1909 年京张本线止于张家口；通往内蒙古属于其后平绥—京包演进链。鸡鸣山煤矿支线只用于说明煤炭外运与铁路燃料供给的历史功能。
2. 海淀—乌兰察布“双城计算”是基于已核验政策、合作与网络条件提出的可审计调度模型，不是获批、建成或在运的官方架构。本提交未取得或独立核验项目专属协议、容量、价格、SLA、投资、审批或运行数据。
3. 中东五案例只迁移可解释的机制；每项均写明不可复制、不可推断和在海淀的失效条件。
4. 气候资料为北京市或海淀区级口径，不能替代研究区站点级观测。
5. 所有人工值守、人工呼叫与人工引导均只是“运营主体确认后、经授权服务时段内”的设计目标，不构成人员配置或全天候服务承诺。

## 3. 空间与指标的可信度

九个几何文件是非正式、低置信度的概念表达。`SITE-001` 与三处重点区均为临时粗略边界；用地、建筑干预包络、慢行连线、绿地和公共空间不得解释为法定控规、现状测绘或工程线位。

N4 是 `mobility_stitch`，状态为 `design_only_closed_pending_study`。专项论证前视为未开通；桥、地道、平面过街、遮蔽段、落地空间、绕行和人工值守均未决定。

`metrics.json` 登记 14 项 `known` 与 23 项 `unknown`。已知项主要是提交概念几何的数学结果和申报计数；两个 1.0 只表示申报／文档覆盖度，绝非绩效。官方边界、控制线和现状资料到位后，九个几何层与全部指标必须整体重算。
