# 方案叙事摘要 / Formal Narrative

本方案提出“双轨共生”（Symbiotic Dual-Rail）作为百年京张AI创新带的总体城市设计概念：以京张遗址公园为文化主轴、沿线高校—园区—企业—站点为AI创新副轴，两轨在众智园、北京AI原点社区、大钟寺三处重点区交汇，形成“一带双轨、三核多点、蓝绿复合环”的空间组织。

## 三层范围

- **统筹研究范围**（约 43.6 平方公里）：AI产业生态、双轨共生总体概念、三区两翼协同、5 个全球AI生态案例、文化叙事与品牌命名（英文建议 JZ-AI Belt）。
- **总体设计范围**（约 11.4 平方公里）：六类无缝用地分区、建筑基底与更新项目、交通市政、京张遗址公园活力带与风貌控制。
- **重点区域范围**（约 368.4 公顷）：众智园、AI原点社区、大钟寺三处详细设计。

## 核心空间证据

- `geometry/land_use.geojson`：完整、无缝、无重叠的用地分区。
- `geometry/buildings.geojson`：8 类建筑基底，覆盖研发、加速器、产城综合体、人才公寓、文化展示等。
- `geometry/roads.geojson`：蓝绿慢行主轴 + 纵向产业干道 + 横向社区支路。
- `geometry/green_space.geojson` 与 `geometry/public_space.geojson`：蓝绿与公共空间网络。
- `geometry/phasing.geojson`：近期蓝绿示范、中期产业与人才空间更新的分期。

## 关键指标（EPSG:4548 复算）

- 总体设计范围面积：约 11.41 平方公里
- 绿地比例：约 13.5%
- 公共空间比例：约 7.7%
- AI研发创新用地比例：约 10.0%
- 重点区域：3 处（provisional）
