# Evolutionary Planning 研究说明

## 研究问题

AI 时代的城市设计能否从预设单一终局，转向建立一套在公共价值和法定约束下持续适应的机制？本项目以百年京张的技术演进史为时间参照，以 S03 成府路—五道口—清华园旧站横向断面为完整标本，检验多 Agent 如何生成空间变异、并列分析证据、保存失败与成功谱系，并在不取得公共价值决定权的前提下支持下一代适应。

“演化”不等于越来越先进，只表示在当时的城市宪法、情景与证据条件下更加适应。被选择、保留、调整、休眠、替换和退出的对象，只能是空间方案、设施、运营规则、服务与 Agent 策略，绝不包括居民、社区、企业或任何人类主体。

## 可运行方法

唯一演化配置源是根目录 `simulation.json`。固定随机种子 `20260813` 驱动 D1-D40，每代产生 36 个城市个体，共测试 1,440 个个体。每次变异必须以带来源、权限、可逆性和目标对象的 `MutationCommand` 提交；语言模型不直接改写几何。确定性 Geometry Kernel 检查范围、重叠、最小尺寸与慢层锁定。

选择顺序为：硬约束排除；多个评价 Agent 产生并列向量；按“空间颗粒度 × 公共渗透性 × 时间可塑性”归档生态位；生态位内依据 Pareto 支配、证据可靠性和必要新颖性发生替换；精英基因再繁殖与重组。系统没有单一 fitness、全局冠军或隐藏加权总分。退出个体进入化石库并保留原因，不被删除。

人类不逐项拼接获胜方案。只有出现违法或文保红线、不可逆建设、公共权利冲突、证据低于阈值或 Agent 连续失准时，才能冻结单元、修改城市宪法、补充证据、隔离策略或改变权限。D17 的演示介入仅修改夜间安静约束并重算受影响谱系，未受影响谱系保持不变。

## 双时钟与空间成果

D0-D40 是数字搜索代，形成多个生态位的候选基因库；R0-R3 是现实实施代。D40 自动组合形成的 R1 只是当前可逆表型，不是建成终局。S03 的慢层锁定京张遗产结构和不可侵犯基础设施；中层包括横向通道、首层接口、路缘与公共空间关系；快层包括开放时间、装卸窗口、遮阴、停留、骑行和活动设施。

正式成果共同呈现 R0、D0/D8/D17/D26/D40、D40 生态位精英库、R1 当前表型以及 D41+ 未确定分支。三类规则化压力测试——港口线性城市、山地城市、历史老城——使用同一引擎和接口，只验证协议迁移能力，不冒充真实规划成果。

## 证据边界

公开资料按 verified、background reference、provisional、unknown 四级记录。竞赛提供的设计范围、演化单元和指标用于概念设计、内部复算和协议验证，不是权属、地籍、法定红线或施工坐标。缺少道路工程断面、首层权属和消防、轨道保护条件、竣工设施清单及代表性真实反馈时，系统保持空值、说明影响，并优先生成不依赖精确数值的可逆表达。

## 论文后续结构

1. 固定终局规划在不确定环境中的方法局限；
2. 演化计算、Quality-Diversity、多 Agent 循环与适应性规划的文献基础；
3. City Constitution、城市基因、Geometry Kernel、Agent Ecology 和 Evolution Memory；
4. S03 D0-D40 可复现实验设计；
5. 形态多样性、生态位存续、失败记忆和人工介入结果；
6. 港口、山地、老城迁移压力测试；
7. 自动化偏差、公共价值、数据权利和实施治理边界；
8. 结论：可迁移协议而非自动最优规划。

研究仍需未来真实试验、专业审查与依法取得的公共反馈验证，不宣称代表性共识或实施绩效。
