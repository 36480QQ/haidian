# 方案迭代记录

## v1.1 - 2026-08-29

- 回应“背景过于泛化、设施逻辑脱离真实场地”的复核意见，将学院南路—知春路社区活力段选为代表性区段；这不是把概念包络改成官方红线。
- 增加双语场地校准图，分别表达 OSM 方位、北京市政府公开报道可核验的现状骨架，以及可逆设计叠加边界；明确机器人不得进入主慢行道或跨越遗产铁轨。
- 使用两张不随包分发的北京市政府公开现场照片作为事实视觉参考，生成场地约束概念图；经两轮视觉纠错，把机器人从主慢行道移至侧向铺装支路，并删除错误的机器人轨道支路和伪文字。
- 将新场地约束图设为网页与图册主视觉；原非定位概念体验图降为可迁移操作原型，不再承担地理或现状说明。
- 增补 2026 年街区控规公开摘要、2026 年开放段报道、2024 年二期规划背景、OSM 快照与公开照片参考的来源、授权边界、快照哈希和不分发声明。

## v1.0 - 2026-08-28

- 依据已合并 PR #1045 的 84/100 intake 分和近期 93—96 分迭代的公开评审方法，保持“最慢者测试、八站停靠、非 AI 等价”主概念不变，集中补强可实施性与表达完整度。
- 增加一个非定位、现实状态 `NOT_AUTHORIZED` 的 90 天全停门首启样板：三段研究窗、六道证据门、五类未指派责任角色、硬性 HOLD 条件、人工量与 ROM 成本交接公式。
- 增加六组同任务分列验收与一个明确标注为虚构的低视力访客旅程；任何组的安全关键失败、等价服务缺失或退出失败都不能被总体平均值覆盖。
- 增加 `simulation.json`：12 项固定离线合成任务如实保留两项失败、一个错误载荷和一个审计缺口；10/12 达到合成结果，调度与审计完整度均为 11/12，AI 关闭等价演练为 11/12。读数不冒充现场绩效。
- 使用 OpenAI 内置图像生成能力制作一张无同行素材、无现场照片输入的非定位概念体验图，并清除伪文字；场景只作展示层，已在正文、来源与版权声明中限定。
- 视觉复核否决了首稿中方向含混的穿越铺装和结构错误的自行车；发布稿从零重生，明确横向车道与纵向穿越为 90 度、机器人停在停止线外，并只保留一辆无遮挡且机械连接完整的标准自行车。
- 新增试点协议与演练读数双语图件，重建双语 A3/A0 与离线视觉页，减少空白并把人的旅程、失败项和实施门放到首屏。
- 迁移至 manifest `0.2.x`、标准 ID 独立命名空间与持久化自检契约；迭代完成后使用最新四门检查重新生成 `self_check.json`。
