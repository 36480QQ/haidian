# V6 方案叙事摘要

V6 针对 Review Agent 74/100 暴露出的图纸问题进行集中修复。方案不再把 A0 首页作为窄长边界上的概念证据图，而是把它重做为总体城市设计总平面：街区肌理、站城关系、建筑群落、公共空间连续性、首层公共界面、三处重点区和算法门槛同时进入同一张主图。

本轮核心设计决断为四项：保留铁路遗产骨架和可再利用建筑，打开围墙、停车边界和低效首层，加密三处公共庭院周边的研发、人才、国际交流和可信数据试验功能，把三庭与百年智轨慢行主脊确立为 AI+ 公共主场景。算法规则不再主要作为流程框出现，而是直接影响慢行缝合线、首层开口、树荫雨洪、公共价值护照和 G0-G4 退场门槛。

V6 仍保留专业边界：官方红线、重点区 CAD/GIS、控规、权属、建筑测绘、市政、消防、交通、树木、热环境、成本和公众参与资料仍需外部提供。方案不伪造这些资料，而是把它们列为正式深化和实施前置条件；当前图纸用于开源征集概念设计和可复算审查。

## V7 内外评分校准分析

V7 把参赛者内部自评从“完成度/合规自信”改为“外部 Review Agent 分数预测”。结论很直接：历史最高外部分数是 PR #709 的 78/100，当前 V6 的外部分数是 71/100；因此后续内部评分必须以 78 作为基线，而不是继续使用 97+ 或 88 这类无法被外部结果支持的自评。

| PR | 版本 | 内部自评 | 外部 Review Agent | 观察 |
|---|---:|---:|---:|---|
| #166 | 初版 | 未声明 | 71 | 完整进入接收，但概念和证据深度只是基线。 |
| #709 | V3 公共价值协议 | 未声明 | 78 | 历史最高；公共价值护照、第一性问题、数字协议和证据锚点最强。 |
| #1579 | V5 空间图纸先行 | 97.8 | 74 | 图纸和闭环改善，但公共价值协议和证据密度弱于 V3。 |
| #1592 | V6 城市形态优先 | 88.0 | 71 | 图纸表达增强，但机器可见的协议、证据和硬参数没有同步增强。 |

内部评分失准的主要原因是把 gate 当 score。确定性校验、自检、双语和渲染完整是入场门槛，不等于内容高分；图纸观感提升也不会自动转化为外部加分，除非它绑定硬空间参数；减少证据锚点改善了可读性，但降低了机器可见的来源、数据、深度和指标支撑。

新的内部评分权重改为：公共价值协议 18，证据锚点与可追溯性 18，第一性问题与方案比选 12，算法治理合同 12，城市设计形态与空间具体性 14，实施具体性 10，风险、数据边界与合规 8，双语包装与渲染完整性 8。后续自评不得再使用“97+”作为内容质量声明；允许声明的是 gate readiness passed，内容分只用外部校准预测区间表达。

## V8 校准后修改方案

V8 不把上一轮降分简单归因于“图纸还不够漂亮”。外部记录显示，V3 的 78/100 高点来自公共价值协议、第一性问题、证据锚点和可撤回治理合同；V5/V6 的视觉表达加强后，分数反而下降，说明评审更看重可审计的设计判断，而不是孤立的版面完成度。因此 V8 的修改策略是：恢复 V3 的高分结构，保留 V6 的空间图纸，但把图纸降为证据载体，把公共价值、硬参数和治理门槛重新升为主轴。

V8 对 `proposal.md` 和 `proposal.en.md` 做了五类内容级修订。第一，执行摘要改为“把创新密度转化为公共价值”，明确竞赛核心不是展示 AI 概念，而是把研究、产业、教育、社区和国际交流转化为沿京张铁路可进入、可维护、可复算的公共城市基础设施。第二，恢复第一性问题与三方案比选，把“媒介走廊”“地标集群”“公共价值共同体”并列比较，最终选择第三种路线。第三，恢复公共价值护照和数字化城市设计协议，要求每项干预绑定受益对象、空间对象、证据等级、运营责任、非数字替代和退出条件。第四，补足三庭差异化，把北段协议庭、中段原点开源站、南段大众未来广场分别落到总平面、剖面、首层界面和运营时序。第五，新增硬规划参数表，把站点、庭院、绿地覆盖、建筑包络、慢行网络、强度控制和运营指标转成可审查对象。

校准后的内部预测不再使用 88 或 97+。V8 的参赛者侧预测为 78–82，点估计 80。达到 78 的依据是恢复了历史最高版本的公共价值协议、第一性问题和证据结构；可能超过 78 的依据是增加了 V3 当时较弱的硬空间参数、三庭差异化和双语渲染完整度。分数上限仍受三项条件限制：官方红线和 CAD/GIS 缺失，建筑保存/拆改清单仍为设计假设，成本与产权主体未外部确认。因此 V8 是“对准外部分数模型的内容修复”，不是最终 85+ 施工深化版。

## V8.1 图纸可见化修订

V8.1 继续执行校准结论，把 V8 文本中的硬规划参数推进到图纸层。中英文总体主图、三重点区、硬参数用地结构、慢行蓝绿、公共价值协议和指标证据六组核心图已重生成；A0 展板与 A3 图册同步重生成。新版图纸要求远看先读出“一脊三庭两翼”的城市结构，近看再读出三庭差异、首层公共界面、慢行断点、公共价值护照、证据边缘和 UNKNOWN 复核门槛。

这一步解决的是 V8 仍偏“文本校准”的问题。现在 `visual/assets/hard_parameter_spatialization_v8.json` 把总体图层、三重点区参数、硬指标证据和评分校准边界结构化，图纸不再只是视觉包装，而是机器可读参数的空间表达。内部预测仍保持 78–82，不因重绘图纸上调到 85+；因为官方 CAD/GIS、建筑测绘、权属、消防、交通、市政、成本和公众参与资料仍未到达实施级深度。

下一轮若要冲击 85+，优先级应为：用官方资料替换临时边界和概念几何；把建筑保留/更新清单、界面开口率、慢行断点、服务半径和责任主体做成可复算表；为三个重点区分别补完整公共价值护照实例；最后再刷新图纸、HTML、manifest 和 CI。
