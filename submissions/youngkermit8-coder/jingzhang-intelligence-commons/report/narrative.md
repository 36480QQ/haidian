# V4 方案叙事摘要

V4 的核心是空间图纸先行。方案以总体城市设计主图建立“百年智轨主脊、三处公共庭院、两条创新翼、十二个 AI+ 场景”的主次结构，再通过三处重点区的总平面、剖面、首层公共界面和运营时序补足可比较的城市设计深度。

算法表达被压回空间对象：公共价值护照、证据等级、数据合同、人工复核和停止门槛直接贴附在线、面、点和分期上。指标仍保留，但只作为边缘证据，避免方案退化为看板。

所有边界、面积和空间对象继续保持开源可复算。临时边界不作为官方红线；总建筑面积、容积率、高度、密度、退线、权属和市政容量保持 unknown，待正式资料发布后整体替换复算。

按仓库正式评分七维权重进行参与者侧严格自查，V4 保守自评分为 91.6/100。该分数不是官方评审结论，而是基于 gate 全通过、PDF 渲染抽检、空间图纸优先、三重点区深描、算法叠图、实施矩阵和风险边界的自审记录；完整扣分理由见 `visual/assets/formal_score_self_audit_v4.json`。未达到 95+ 的主要原因仍是官方红线、权属、交通、市政、消防、成本、公众参与和现场测绘资料缺失。
