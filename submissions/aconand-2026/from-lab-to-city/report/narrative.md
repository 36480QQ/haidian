# 技术叙事与成果关系

本方案以 `proposal.md` 为中文主叙事、`proposal.en.md` 为英文对照稿。两份文本共同解释“让创新走进日常 / FROM LAB TO CITY”：以京张铁路遗址公园串起三个站点——众智园先把原型试清楚，AI 原点先把服务讲清楚，大钟寺再把成果放进日常。每个项目都按“提出问题 → 做出原型 → 讲清服务 → 小范围使用 → 带回反馈”推进，把故障、维护成本、召回和公众意见送回下一轮研发。

区域协同采用可追踪的任务交接，而不是泛化的招商连线：中关村 AI 北纬社区、未来科学城、怀柔科学城、北京经开区和京津冀分别通过任务、测试证据、反馈与停止条件同京张带连接。该框架来自官方公开角色的设计推导，不代表任何机构已承诺项目、资金、场址、设施或数据共享。

结构化几何位于 `geometry/`。这些文件是依据仓库临时粗略边界生成的低置信度概念模型，不是正式红线、测绘成果或法定地块。`metrics.json` 使用 EPSG:4548 对同一组 GeoJSON 复算面积和比例；不能可靠复算的容积率、高度、真实临街使用范围、无障碍入口密度和存量复用率明确保持 `unknown`。

`compliance_matrix.json`、`standard_matrix.json` 和 `design_depth_matrix.json` 分别记录任务响应、专业标准和设计深度证据。`assumptions.json` 与 `risk.json` 保存资料缺口、释放条件和专业复核要求。图件、A3 文册、A0 展板、离线 HTML 阅读版和 `visual/index.html` 均是上述数据合同的展示层，不构成新的权威数据源。

本成果是概念性城市设计建议，不是法定规划、测绘交付、工程可行性研究、投资承诺或政府批准。正式控规附件、测绘、权属、建筑普查、交通与轨道、市政、防洪排水、文保、运营主体和预算资料到位后，所有相关几何、指标和实施判断必须重算与专业复核。
