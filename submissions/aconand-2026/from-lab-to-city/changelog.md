# 方案迭代记录

本文件记录方案如何回应反馈、修订表达，并保留仍需专业深化的事项。它不是政府审定记录或实施承诺。

## v0.7 - 2026-08-26

### 修复七维评审的离线中文缺字

- 针对 PR #4000 七维评审中“中文报告与可视化大量汉字显示为方框”的唯一视觉门阻断，检查了四个 HTML 的实际字体链路，确认原页面只依赖 Windows/macOS 中文系统字体。
- 从 SIL Open Font License 1.1 许可的 Noto Sans SC 中提取四个 HTML 实际使用的字形，生成约 288 KB 的可变字体子集；考虑仓库不允许直接提交 `.woff2`，将子集和完整 OFL 许可证内嵌到允许提交的本地 CSS，并以 `FTLC Offline Sans` 作为页面专用家族名。
- `report/proposal.html`、`report/proposal.en.html`、`visual/index.html`、`visual/index.en.html` 统一使用同一离线字体，覆盖正文、导航、图注、语言切换和双语辅助文字；字体来源、许可、嵌入/再分发权利及校验值同步登记到 `sources.json`、版权声明和 `manifest.json`。
- 重新渲染并人工核查四页关键状态，再运行视觉包装、完整 self-check 和 participant preflight；本轮不改总体概念、空间策略、指标或临时边界声明。

## v0.6 - 2026-08-24

### 从“概念术语”改为“一眼能懂”

- 根据第二轮用户评阅，正式主标题改为“让创新走进日常 / FROM LAB TO CITY”，空间主张改为“一条公园，三个站点”，不再要求读者先理解“创新链”“站场”等抽象术语。
- 三个站点用日常语言说明分工：众智园先试清楚、AI 原点先把问题和服务讲清楚、大钟寺让成果进入真实使用；项目流程改为“提出问题—做出原型—讲清服务—小范围使用—带回反馈”。
- 以三张 ImageGen 视觉母版确定留白、细线、三点、字体尺度和图文节奏；母版只作审美参考，正式中文、英文、地图和指标全部以 HTML/SVG 可编辑图层重绘，避免生成式文字错误。
- A3 文册和 A0 展板取消大面积色块堆叠，放大结论、图名和正文，直接嵌入可编辑矢量地图，并对中英文长标题、页脚、裁切和阅读尺度逐页检查。
- 官方规则继续采用已锁定的 2026-08-24 基线，不在设计迭代中重复联网查询；发布前只做一次最终 preflight。

### 仍需复核

- “三个站点”是概念性空间与运营角色，不代表现实机构、地块、资金、审批、保险或运营协议已经落实。
- 本轮只更新本地成果；未经账号持有人输入“确认发布”，不执行 push 或创建 Pull Request。

## v0.5 - 2026-08-24

### 从“机器已覆盖”改为“评委能看见”

- 按七项正式 rubric、十三项 Agent 补充维度和六项智能体任务重新检查印刷成果，发现正文中的生态支撑、文化识别、年度运营、场景和人物证据在 A3/A0 中不够显眼。
- A3 第 3 页与 A0 第 2 板新增“八个案例—七要素保障”机制条；案例只提炼可迁移机制，不复制形象，也不虚构资金、企业或政策承诺。
- A3 第 5 页与 A0 第 4 板新增 `CONNECT / TEST / CARE / SIGN` 文化识别和十二项公共空间组件库，使京张工程文化、中关村试错文化、负责任 AI 文化与“一线三点”视觉方向在同一板上可见。
- A3 第 11 页与 A0 第 6 板新增春季问题征集、夏季受控试造、秋季限定首用、冬季公开复盘的年度循环；`FROM LAB TO CITY OPEN WEEK` 只作为建议工作名。

- 中英文四份 PDF 重新渲染，并按联系表与关键页/板高分辨率图逐项检查裁切、页脚冲突、英文换行和阅读尺度。

### 仍需复核

- 八个案例、年度活动、区域交接和场景体系均为研究与概念建议，不代表现实合作、排期、投资、审批或运营授权。
- 总体范围与三处重点区仍为主办仓库临时几何；任何法定、工程和逐地块结论继续保持未知。

## v0.3 - 2026-08-24

### 采纳的反馈

- 用户指出早期抽象的边界隐喻难以理解，A3 文册和 A0 展板存在中文不自然、信息平均用力、重点不突出的问题。
- 对用户提供的优秀 A3 文本与 A0 展板案例进行逐页学习，重点吸收“一页一个结论、标题使用日常语言、大图承担论证、文本册与展板分工”的方法。

### 本轮修改

- 将总体概念重构为“公园里的创新链 / FROM LAB TO CITY”，核心句为“从实验室到城市，再把城市反馈带回实验室”。
- 以“一条公园主线、三处创新站场”重组空间叙事：众智园试造场、AI 原点转化站、大钟寺首用街。
- 重写中英文正文、12 页 A3 文册和 7 张 A0 展板，降低术语密度，建立远看主张、近看证据的阅读层级。
- 新增三处重点区合成场景图，并与总体鸟瞰一起完成生成记录、权利声明、6K 下载、投稿压缩和印刷派生。
- 将公开目录与 `package_id` 统一为 `from-lab-to-city`，清除离线展示页中的本机绝对路径，确保成果移到其他电脑后仍可打开。

### 仍需复核

- 总体范围和三处重点区仍使用主办仓库提供的临时几何，不是官方红线；正式图则、测绘、权属、现状建筑、交通、市政和文保资料到位后必须重算。
- 容积率、建筑高度、存量复用率、界面长度等无可靠底数的指标继续保持未知。
- 本轮只完成本地成果与校验；fork、push 和 Pull Request 尚未执行。
