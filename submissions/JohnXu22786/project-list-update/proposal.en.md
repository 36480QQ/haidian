# RENEWAL PROJECT LIST ECOSYSTEM (RENEW.JZ) (Concept)

**English convenience summary** (full binding narrative is the Chinese proposal.md; this summary may lag the zh text).

以「更新清单智环（RENEW·JZ · 更新项目清单专项）」构建沿京张AI创新带的更新项目清单专项概念：以「项目盘」为更新项目决策中枢（更新项目库汇聚、比对与可视化决策，匿名聚合服务），「样板街」为更新示范街道（留改拆并举示范与实施进度可见，公开口径校核），「协同厅」为更新协同服务站点（政府、产权人、公众与AI工具协同，人工复核兜底），五类AI+场景（更新项目台账AI、更新进度跟踪AI、拆改留合规核验AI、更新效果评估AI、公众更新意见反馈AI）仅处理匿名聚合数据、关键决策人工复核、禁止过度监控，交通慢行优先、连续慢行轴贯通三节点、蓝绿公共空间低干预融合布置，三项formal核心指标（site_area_sqm、green_ratio、public_space_ratio）以本包几何复算、面积以官方文本口径为底，分期实施+清单滚动与公示计划。全部为概念建议、参考方案，不给出容积率、建筑高度、具体拆改留或工程实施结论，不编造拆建数据，基于 provisional 边界，官方数据发布后复算。

## Outline
- Renewal Project List Ecosystem (RENEW.JZ): a concept for a renewal project list special scheme along the Jingzhang AI innovation belt, using the heritage green belt as the backbone.
- Project Deck as the renewal project decision hub: consolidated renewal project library, comparison and visual decision support, anonymized aggregation only (concept-level mechanism suggestion, not statutory statistics).
- Model Street as the renewal demonstration street: retain-renovate-demolish demonstration and implementation progress display with public-source calibration (concept-level).
- Collaboration Hall as the renewal collaboration service station: government, property owners, public and AI tools collaborate, human review as backstop.
- Node 1 - Project Deck: decision hub. Node 2 - Model Street: demonstration street. Node 3 - Collaboration Hall: collaboration station.
- 5 AI+ scenarios (renewal project ledger AI, renewal progress tracking AI, retain-renovate-demolish compliance check AI, renewal outcome evaluation AI, public renewal feedback AI); anonymized aggregation only, key decisions human-reviewed, no over-surveillance.
- Slow-traffic-first: a continuous slow-traffic axis along the green belt links the three nodes; blue-green public spaces host low-intervention, reversible renewal service facilities; annual events: renewal project open day, renewal progress briefing, model street experience week.
- Three formal core metrics (site_area_sqm, green_ratio, public_space_ratio) are recomputed from this package's geometry; all figures are concept suggestions on a provisional boundary; recompute when official data is published.
