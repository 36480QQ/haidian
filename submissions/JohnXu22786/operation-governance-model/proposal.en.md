# GLOBAL AI INNOVATION EVENT & LONG-TERM OPERATION LOOP (OPS.JZ) (Concept)

**English convenience summary** (full binding narrative is the Chinese proposal.md; this summary may lag the zh text).

以「运营智环（OPS·JZ · 一带全球AI创新活动体系与长期运营设计）」构建沿京张AI创新带的长期运营机制专项概念（对应任务书agent.6：年度活动体系、活动品牌与传播视觉系统、开发者社区运营机制、AI场景开放运营机制、公共体验和城市地标运营、国际传播和招引转化机制）：以「活动中枢」为年度活动体系与活动品牌传播视觉系统中枢（活动排期、品牌IP与传播规范聚合管理，匿名聚合服务），「开发者工坊」为开发者社区运营站（社区运营机制与人才转化路径），「场景开放台」为AI场景开放运营台（公共体验与城市地标运营、国际传播与招引转化，人工审核兜底），五类AI+场景（活动运营AI、社区问答AI、场景监测AI、传播内容AI、招引转化AI）仅处理匿名聚合数据、关键决策人工复核、禁止过度监控（不进行个体识别式追踪），交通慢行优先、连续慢行轴贯通三节点、蓝绿公共空间低干预融合布置，三项formal核心指标（site_area_sqm、green_ratio、public_space_ratio）以本包几何复算、面积以官方文本口径为底，分期实施+年度复算与公示计划。全部为概念建议、参考方案，不给出容积率、建筑高度、具体拆改留或工程实施结论，不编造数据，不夸大政府承诺或活动效果，基于 provisional 边界，官方数据发布后复算。

## Outline
- Global AI Innovation Event & Long-term Operation Loop (OPS.JZ): a concept for the belt-wide global AI innovation event system and long-term operation governance, following taskbook agent.6 (annual event system, event brand and communication visual system, developer community operation, scenario open operation, public experience and landmark operation, international communication and attraction conversion).
- Event Hub as the annual event system and event-brand communication hub: event scheduling, brand IP and communication standards, anonymized aggregation only (concept-level mechanism suggestion, not statutory procedures).
- Developer Workshop as the developer community operation station: community operation mechanism and talent conversion pathways (concept-level).
- Scenario Open Deck as the scenario open-operation platform: AI scenario open operation, public experience and landmark operation, international communication and attraction conversion (concept-level).
- Node 1 - Event Hub: annual event system. Node 2 - Developer Workshop: developer community operation. Node 3 - Scenario Open Deck: scenario open operation and conversion.
- 5 AI+ scenarios (event operation AI, community Q&A AI, scenario monitoring AI, communication-content AI, attraction-conversion AI); anonymized aggregation only, key decisions human-reviewed, no over-surveillance (no individual-identifying tracking).
- Slow-traffic-first: a continuous slow-traffic axis along the green belt links the three nodes; blue-green public spaces host low-intervention, reversible event and operation facilities; annual events: Global AI Innovation Week, developer hackathon season, open-belt public day.
- Three formal core metrics (site_area_sqm, green_ratio, public_space_ratio) are recomputed from this package's geometry; all figures are concept suggestions on a provisional boundary; recompute when official data is published.
