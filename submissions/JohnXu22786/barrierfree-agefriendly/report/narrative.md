# 方案叙述（Formal Narrative）

本叙述由结构化 AI 包派生：几何（geometry/）、指标（metrics.json）、合规矩阵（compliance_matrix.json）、标准矩阵（standard_matrix.json）、设计深度矩阵（design_depth_matrix.json）、图件（assets/figures/）、图册（drawings/）与可视化页（visual/index.html）均为交叉核对的交付物。

## 方案主线

「宜老智环（CARE·JZ · 无障碍与适老化环境体系）」以京张铁路遗址公园绿带为骨架，构建沿京张AI创新带的连续无障碍慢行网络与三个原创概念节点：无碍驿（无障碍慢行与接驳服务节点）、宜老坊（适老化社区更新示范单元）、智伴亭（AI辅助适老化公共信息服务站点）。任务书三大定位、五大功能与三区两翼在统筹研究层映射，十张场景卡与三项产业测试验证方案在总体设计层落地，分期实施与年度运营机制面向长期价值。

## 证据链

正文各节均附机器可读证据锚点（[source]/[standard]/[depth]/[data]/[metric]）；structured JSON 保存完整索引；全部语义数据（面积、比例、计数）以 geometry 与 metrics.json 为准，provisional 边界与低置信度指标一律降精度显示并在官方数据发布后触发复算。

## 诚实边界

本包全部为概念建议、参考方案：不给出容积率、建筑高度、拆改留、投资、客流与容量等结论性数字；不编造官方数据；AI 场景仅处理匿名聚合数据、关键决策人工复核、禁止过度监控；居民意见通道、年度公示与年度活动为机制方向；品牌名称为内部工作代号。
