## 4. Fonts
- visual/index.html, visual/index.en.html, report/proposal.html, report/proposal.en.html: the four HTML surfaces embed an OFL-licensed Noto Sans SC subset as a base64 @font-face data URI (`Noto Sans SC Subset`), forced first in the font-family stack (embed_fonts.py; re-applied after every HTML render). The OS-installed font stack (Microsoft YaHei / PingFang SC / Noto Sans CJK SC) remains as fallback.
- Figures and PDFs (matplotlib renderings): use the OFL-licensed Noto Sans SC / DejaVu Sans for glyph rendering; PDF output embeds glyph subsets of OFL fonts for offline viewing. No proprietary font binaries are distributed.
