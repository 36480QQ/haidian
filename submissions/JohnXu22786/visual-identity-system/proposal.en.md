# VISUAL IDENTITY ECOSYSTEM (VIS.JZ) (Concept)

**English convenience summary** (full binding narrative is the Chinese proposal.md; this summary may lag the zh text).

以「视觉识别智环（VIS·JZ · 视觉识别系统专项）」构建沿京张AI创新带的视觉识别系统专项概念：以「主视台」为视觉识别中枢（主视觉、Logo方向与品牌规范体系，匿名聚合服务），「导视廊」为导视标识示范段（导视、标识、符号系统与公开口径校核），「叙视厅」为叙事展示站（京张铁路历史文化与AI新文化叙事表达载体，人工复核兜底），五类AI+场景（视觉规范校验AI、导视内容生成AI、标识信息维护AI、叙事内容策展AI、公众视觉反馈AI）仅处理匿名聚合数据、关键决策人工复核、禁止过度监控（不进行个体识别式视觉追踪），交通慢行优先、连续慢行轴贯通三节点、蓝绿公共空间低干预融合布置，三项formal核心指标（site_area_sqm、green_ratio、public_space_ratio）以本包几何复算、面积以官方文本口径为底，分期实施+年度复算与公示计划。全部为概念建议、参考方案，不给出容积率、建筑高度、具体拆改留或工程实施结论，不编造数据，基于 provisional 边界，官方数据发布后复算。

## Outline
- Visual Identity Ecosystem (VIS.JZ): a concept for a visual identity system special scheme along the Jingzhang AI innovation belt, using the heritage green belt as the backbone.
- Visual Hub as the visual identity hub: master visual identity, logo direction and brand standards, anonymized aggregation only (concept-level mechanism suggestion, not statutory statistics).
- Signage Gallery as the signage demonstration segment: wayfinding, signage and symbol system with public-source calibration (concept-level).
- Narrative Hall as the narrative display station: Jingzhang railway heritage and new AI culture narratives, human review as backstop.
- Node 1 - Visual Hub: identity hub. Node 2 - Signage Gallery: signage demonstration segment. Node 3 - Narrative Hall: narrative display station.
- 5 AI+ scenarios (visual standard check AI, wayfinding content generation AI, signage information maintenance AI, narrative curation AI, public visual feedback AI); anonymized aggregation only, key decisions human-reviewed, no over-surveillance (no individual-identifying visual tracking).
- Slow-traffic-first: a continuous slow-traffic axis along the green belt links the three nodes; blue-green public spaces host low-intervention, reversible signage and display facilities; annual events: visual identity open day, wayfinding update briefing, visual experience week.
- Three formal core metrics (site_area_sqm, green_ratio, public_space_ratio) are recomputed from this package's geometry; all figures are concept suggestions on a provisional boundary; recompute when official data is published.
