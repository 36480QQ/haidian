# 京张城市版本 / JINGZHANG URBAN VERSIONS

本文件为提交包导航。正式双语叙事见 `../proposal.md` 与 `../proposal.en.md`；图纸、GeoJSON、指标、来源、标准响应、风险与假设在同一提交包中交叉校验。

本版以 2026 年 8 月全线开放、报道所载约 9 km 和约 53 ha 的京张铁路遗址公园为公共基线，提出三类决策试验场和一个年度项目复盘机制。Urban Patch 001 首次把大钟寺横向连接的 A/B/C 空间原型、公开权重、硬门槛、现场证据最小包、绩效合约与退出责任做成可复现的双语离线实验台。AI 参与备选生成、多目标比较、敏感性分析和实施后复测；六项证据未齐即保持不决策，法定权限、专业判断与公共利益权衡仍由责任主体承担。

所有临时边界、任务锚点和关系线只用于概念研究，不构成官方红线、测绘成果、法定规划、工程方案或政府批准。
