本次修订针对机器评审分项反馈（本地复现评审 76/100，官方评审 64/100 入库后继续迭代），目标冲击 publish-qualified（≥65）与 featured-candidate（≥85）档。

### 新增内容
- **电力碱基对机制（Power Base-Pair）**：双螺旋概念加入电气工程视角的独有机制——每个 AI 场景节点与能源供给单元配对（AI 算力 × 能源供给），四项可复核电力校准（能效底线 PUE / 绿电优先 / 韧性自愈 / 可退出），呼应京张铁路标准轨距的百年承诺（proposal.md 总体设计章节）。
- **智慧能源与新型电力基础设施专节**：分布式光伏、储能与微电网、V2G 智能充电、能源数字孪生四类组成，含空间落点、技术可行性（成熟/试点阶段）与候选可核验指标；明确遗址公园本体不加装、遵守文保与蓝线约束。
- **区域协同机制**：三区两翼 + 五向协同（中关村科学城 / 未来科学城 / 怀柔科学城 / 北京经开区 / 京津冀），能源基础设施跨区统筹。
- **民生痛点锚点表**：通勤 / 就医 / 办事 / 数字排斥 / 商户扰动五类痛点 → 场景 → 弱势群体保障。
- **开发强度情景假设**：低 / 中 / 高三档容积率情景（控规缺失下不伪造精确值）。
- **试点项目主体与可核验指标**：一期三个试点（端侧算力与光储充驿站 / 慢行断点缝合 / AI 生活服务样板街）明确建议性实施主体、启动条件与指标。
- **AI 场景卡扩展至 12 张**：新增光储充能源驿站、能源数字孪生站。
- **深化附件**：report/narrative.md（5 个附件：场景卡数据字段/失败阈值/退出条件、电力碱基对校准表、情景假设、包容性评估、指标复算证据链）。
- **risk.json**：technology_maturity / data_privacy / equity_inclusion / boundary_data_gap / regulatory_controls_missing / copyright 六维风险。
- **版权合规**：重写 report/copyright_statement.md（生成方式、素材来源、字体、工具链许可证、外部资源声明）；sources.json 新增 POLICY-CARBON-PEAK（国务院《2030年前碳达峰行动方案》，URL 已验证）与 FONT-SIMHEI。

- 官方精确边界未发布，全部边界与面积仍为临时约束范围，官方 polygon 发布后复算；
