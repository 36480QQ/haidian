## v2 的变化

1. Paris-Saclay 不再只是“科研集群”样本，而是“科研城市化的未完成实验”：住房完成不足、周末活力不足等反向证据进入生活完整性检查。
2. Tonsley 的公众试乘、车载 chaperone 与远程监督进入 S07；仍把拒绝、保险、事故停机等未核实项保留为闸门，不写成既成制度。
3. Helsinki 的登记字段扩展到人工责任、日志期限、无障碍、反馈和下线，但登记册仍只是透明基础设施，不替代独立审计与法定救济。
4. Toronto 的 Sidewalk 阶段只作为权限边界、缩范围、停止和重新采购的治理反例；当前 Quayside 与历史提案分开处理。
5. STATION F 从主案例降为 AI 资源台的机制补充；Boston Seaport 虽有新证据，但与 Kendall/Cortex 的机制重复度高，继续不进入主案例。

图中箭头表示“机制转译关系”，不表示案例之间存在直接合作，也不表示京张已经确定建设、采购、运营或维护这些机制。v2 图与 `全球AI创新生态案例-京张机制转译矩阵-v2.csv`、`场景双生卡-v5.csv`、`D8-D9-三阶段项目清单-v3.csv` 联读。
