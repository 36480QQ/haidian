# 公开数据检索清单

本清单只规定背景资料和待核范围，不把未取得的数字写成预测性成效，也不替代正式规划资料。每次回来迭代前，按“同步主分支—复读官方说明—检查 Issues/PR—更新来源台账—重新自检”的顺序执行。

| 数据层 | 首选公开来源/检索入口 | 需要登记的字段 | 当前状态与限制 |
|---|---|---|---|
| 区级人口 | 北京市/海淀区统计公报、统计年鉴和街道公开资料 | 行政口径、年份、空间单元、URL、获取日期、许可 | 只作背景；待按统一年份和空间口径核对，不用于预测客流 |
| 轨道与客流量级 | 北京交通、轨道运营方或政府公开运行信息 | 站点、时段、统计口径、是否客流/断面、URL、获取日期 | 只记录量级和定义；没有官方口径时保持 unknown |
| POI 与公共服务 | 政府公共服务目录、开放地图或有许可的机构数据 | POI 类型、位置精度、更新时间、许可、去重方法 | 只用于发现服务缺口和待核点，不上传个人或未授权数据 |
| 控规与用地 | 规划自然资源部门公开规划、控规检索和正式图则 | 图则编号、版本、地块/道路口径、URL、获取日期 | 临时边界不能替代控规；正式图则到位后重算面积、用地和强度 |
| 无障碍与人工服务 | 政府服务指南、站点设施说明和现场专业核查清单 | 入口、坡道/电梯、服务时段、人工入口、核验人/日期 | 网络资料不等于现场证据；无现场核验时保持待核 |

## 统一登记规则

- 每条记录写明来源、用途、限制、获取日期、空间/时间口径和可否复用。
- 不能公开验证的链接不进入 `sources.json` 的事实来源，只保留为内部待检索任务。
- 任何人口、客流、POI 或控规数字在进入图件/指标前，必须由人工复核并记录版本；未完成时正文使用“待核/unknown”。
- 不收集个人隐私、连续轨迹、面部信息或未获授权的内部规划资料。
