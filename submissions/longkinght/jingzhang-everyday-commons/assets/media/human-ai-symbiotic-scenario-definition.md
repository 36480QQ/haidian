# 人机共生场景｜Human–AI Symbiotic Scenario

**副标题 / Subtitle:** AI路径与人工/离线路径并行的公共服务场景 / A public-service scenario where AI and human/offline paths remain available in parallel.

本机制为概念设计，不表示已经部署、获批或完成现场测试。This is a conceptual design mechanism; it does not claim deployment, approval or completed field testing.

## 定义｜Definition

人机共生场景让同一个公共任务同时具备可解释的 AI 路径和不受歧视的人工/离线路径，并把选择、人工决定、停止、恢复和退出落实到同一组公共空间接口。AI可以建议、解释、导航和分流；人类责任角色负责放行、暂停、纠错和恢复。

A Human–AI Symbiotic Scenario gives the same public task both an explainable AI path and a non-discriminatory human/offline path, then locates choice, human decision, stopping, restoration and exit in the same public-space interfaces. AI may advise, explain, navigate or triage; an accountable human role releases, pauses, corrects and restores the service.

## 五个必要字段｜Five required fields

| 字段 / Field | 判定 / Test |
|---|---|
| 同一公共任务 / Same public task | 两条路径具有相同起点、基本结果和完成条件；普通路径不额外收费或降级 / Both paths share the same origin, essential outcome and completion condition; the ordinary path is not downgraded or surcharged |
| AI路径 / AI path | 输入来源、输出、版本、不确定性、人工复核和错误处理均可见 / Inputs, output, version, uncertainty, human review and error handling are visible |
| 人工/离线路径 / Human or offline path | 无AI、故障或拒绝时，人工、电话、纸面、固定导视或无账号入口仍可完成任务 / Human, phone, paper, fixed-wayfinding or account-free access completes the task without AI |
| 共同空间 / Shared space | 两条路径在可定位的入口、导视、服务台、观察位、状态牌或退出构件中相遇和回退 / The paths meet and fall back at a locatable entrance, sign, desk, observation point, status board or exit element |
| 停止与恢复 / Stop and restore | 阈值、责任角色、回退、公开状态、恢复闸门和记录期限明确 / Threshold, accountable role, fallback, public status, reopening gate and record period are explicit |

缺少任一字段，均不得使用“人机共生场景”这一名称。If any field is missing, the service is not a Human–AI Symbiotic Scenario.

## 三个反例｜Three counterexamples

1. **纯AI目录 / AI-only directory:** 必须注册的二维码服务，没有人工、电话或纸面入口；缺少人工路径和停止恢复。A registration-only directory lacks a human path and stop/restore process.
2. **免责声明式人工兜底 / Disclaimer-only fallback:** 只写“必要时转人工”，没有入口、时段、角色和动作；缺少可使用的共同空间。A vague “refer to staff if needed” clause has no usable spatial interface.
3. **无空间后果的后台流程 / Back-office AI with no spatial consequence:** 公众看不到AI何时进入、谁决定、怎样拒绝和纠错；缺少共同空间与公众选择。Invisible back-office AI has no shared-space consequence or public choice.

## 状态｜States

`资料准备 / evidence preparation → 桌面或合成验证 / tabletop or synthetic validation → 试点就绪设计 / pilot-ready design → 拟议有限使用 / proposed limited use → 扩大、暂停或退出 / scale, pause or exit`

桌面/合成验证不证明现场绩效；试点就绪设计不证明场地授权、责任主体签约或真实使用。Tabletop or synthetic validation does not prove field performance; pilot-ready design does not prove site authorization, accountable-entity commitment or real-world use.

S01 applies the mechanism to accessible rail-to-park arrival. S06 and S07 reuse the five-field protocol for first-use explanation and controlled robot observation, but their spatial consequences remain different.
