- Scope: single Dazhongsi flagship; no report pages, dashboards, plans or matrix shots.
- Story: BASE → ACTIVE → FREEZE → HUMAN HANDOVER → RETURN → BASE.

## Transcript / 文字稿

1. **OPENING** — 城市必须先在没有人工智能的状态下工作。 / The city must work before AI is switched on.
2. **BASE** — 普通路径和人工服务先成立，任何人都能完成原来的任务。 / The ordinary route and staffed service come first, so the original task remains possible for everyone.
3. **ACTIVE** — 经过人工批准，可逆服务只在边缘展开，主通道始终开放。 / After human approval, the reversible service opens only at the edge while the main route stays clear.
4. **FREEZE** — 拥堵或侵线发生，设备立即锁定，工作人员接管。 / Crowding or encroachment locks the equipment immediately and staff take over.
5. **HUMAN HANDOVER** — 人工接管不是遮掩失败，而是城市继续运行的基础设施。 / Human takeover does not hide failure; it is infrastructure that keeps the city working.
6. **RETURN** — 设备退出以后，留下座椅、遮阴、导视和一条始终清晰的路。 / After the equipment leaves, benches, shade, wayfinding and a continuously clear route remain.
7. **CLOSING** — 失败，不占用城市。 / Failure does not occupy the city.
