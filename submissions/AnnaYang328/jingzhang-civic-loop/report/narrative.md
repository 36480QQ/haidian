# 正式成果说明 / Formal Narrative

《京张问道：城市回路》以“百年轨道未止于抵达，智能之城始于回应”为文化主张，将京张铁路遗产组织为公共知识与创新验证线，将众智园、AI 原点和大钟寺分别组织为校准、共创和反馈三站。三站共同形成一个允许项目验证、有限使用、反馈、返回、暂停和退出的城市学习回路。

正式成果包包含：中英文完整方案、中英文五张核心图、九页 A3 文册、三张 A0 展板、双语离线评审浏览页、GeoJSON 图层、指标与假设、来源登记、任务/标准/设计深度矩阵及四层自检结果。机器权威顺序为 GeoJSON → metrics → matrices/manifest → narrative → figures/HTML/PDF。

当前总体边界和三处重点区为 provisional constraint，只支持设计讨论、结构校验和面积复算，不是官方红线。正式边界、控规、道路、权属、现状建筑和市政资料到位后，所有几何、指标和图纸须整体重算。

The English package is a full counterpart rather than a summary. It uses the project glossary consistently and preserves the same claims, evidence boundaries, metrics, figures, drawings, and risk disclosures as the Chinese package.
