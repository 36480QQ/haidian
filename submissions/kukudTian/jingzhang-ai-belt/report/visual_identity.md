# OPEN-JZ 视觉识别规范 · Visual Identity（agent.1 / agent.5）

> 回应评审：需提供可识别的正式 Logo 构形、标志网格、最小尺寸、黑白版与授权字体方案。

## 1. Logo 构形
- **主标识**：京张铁路工字钢轨截面（I）与代码尖括号（&lt;&gt;）同构叠加，形成「JZ」双字母意象；下方辅以三色状态灯（● 绿=正常运行 / ● 黄=试验中 / ● 红=需人工评审）
- **标准色**：深夜蓝 #0A0E1A（底色）、荧光绿 #00FF9C（主色，象征运行状态）、代码白 #E8F0FE（文字/图形）、警示黄 #FFD166（仅用于试验中状态）
- **标志网格**：以 8×8 单位网格为基准，尖括号开口角度 60°，工字钢翼缘宽度 1 单位，状态灯直径 1.5 单位、间距 2 单位
- **最小尺寸**：数字媒体 ≥ 24px；印刷 ≥ 8mm；低于最小尺寸时仅使用文字锁标
- **黑白版**：单色墨稿为纯黑 #000 反白 #FFF 两版，用于公文、雕刻、烫印等场景
- **安全区**：四周留白 ≥ 标识高度的 1/4

## 2. 授权字体方案
- 中文：思源黑体（Noto Sans SC，SIL OFL 1.1 开源许可，可自由商用）
- 英文/数字：与 Noto Sans 配套；等宽强调（代码语境）使用 Noto Sans Mono
- 本方案所有字体均来自开源许可字体，见资产台账 asset_ledger.md

## 3. 状态灯语言（公共标识系统）
- 用于朝圣地标、活动导视、数字界面：绿=正常运行、黄=试验中、红=需人工评审（对应 commit-review-merge-revert 的城市状态）
- 无障碍：状态灯同时以文字/图形标注，不依赖颜色单独传达信息（色盲友好）

## 4. 文化叙事与导视（agent.5）
- 叙事主线：百年京张铁路（自主创新起点）→ 中关村开源（软件产业起点）→ OPEN-JZ（AI 时代开源城市）
- 导视语言：双语（中/英）+ 无障碍（盲文/语音）；沿 MAIN 主线每 500m 设置叙事节点，对应铁路百年纪事
- 国际传播：英文品牌名 OPEN-JZ + 中文「京张代码」，统一用于国际活动与传播物料
