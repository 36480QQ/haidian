# AI 场景卡（10 张完整版）· Scenario Cards

> 每个场景卡包含：定位 / 用户旅程 / 输入数据 / AI 能力 / 基础设施 / 运营主体 / 失败模式 / 隐私与人工复核。
> 全部为概念建议，不构成审批承诺；实施前需完成隐私影响评估（PIA）与审批前置条件核查。

## S01 轨道巡检机器人步道
- **定位**：MAIN 绿脉公共空间的常态巡检与安全感知（遗址公园段）
- **用户旅程**：游客进入公园 → 机器人沿步道巡检并识别占道、破损、异常物 → 上报管理平台 → 养护工单派发 → 处置后回写状态
- **输入数据**：步道视频流、位置轨迹、巡检工单、天气与光照
- **AI 能力**：目标检测（占道/破损/异常物）、路径规划、异常分级
- **基础设施**：绿脉步道 9km、机器人充电坞（每 2km 一处）、边缘计算节点、管理平台
- **运营主体**：海淀区公园养护单位牵头，机器人企业协同
- **失败模式**：误报率高（≤5% 目标）、识别遗漏、夜间失效 → 分级上报 + 人工复核
- **隐私与人工复核**：视频仅用于巡检，人脸默认脱敏；工单与告警均需人工确认后执行；提供电话/小程序申诉通道

## S02 无人配送环线（最后一公里）
- **定位**：三个重点区之间的无人配送微循环
- **用户旅程**：商户下单 → 无人车接单 → 园区路权调度 → 送达取件柜 → 用户凭码取件
- **输入数据**：订单、路况、取件柜状态、路权许可
- **AI 能力**：动态路径规划、多车调度、避障
- **基础设施**：专用配送道（绿脉西侧慢行主路 2.5km）、取件柜、调度平台、充电站
- **运营主体**：平台企业 + 园区物业联合运营，区交通部门监管
- **失败模式**：车辆故障、拥堵绕行、取件失败 → 人工接管 + 客服兜底
- **隐私与人工复核**：订单数据最小化采集；行驶记录留存 30 天；异常订单人工审核

## S03 AI 慢行信号优化
- **定位**：绿脉过街口的自适应信号与行人优先控制
- **用户旅程**：行人接近路口 → 感知设备识别 → 信号延长/优先 → 通过后恢复
- **输入数据**：视频/雷达感知、信号状态、公交到站信息
- **AI 能力**：行人/非机动车识别、预测性信号控制
- **基础设施**：路口感知杆、信号控制器、边缘计算
- **运营主体**：区交通支队 + 信号供应商
- **失败模式**：感知失灵、信号冲突 → 自动回退固定配时 + 人工巡检
- **隐私与人工复核**：感知数据不落盘身份信息；信号策略调整须交管部门审批并公示

## S04 开源代码露天剧场
- **定位**：社区仓（原点社区）的公共展演与开源活动场地
- **用户旅程**：开发者预约 → 参加黑客马拉松/路演 → 成果提交开源仓库 → 展示与评审
- **输入数据**：活动预约、场地状态、直播流
- **AI 能力**：活动推荐、同传翻译、代码评审辅助（AI 预检）
- **基础设施**：露天剧场 0.4ha、舞台、LED 屏、开源平台接入
- **运营主体**：中关村开源社区运营方
- **失败模式**：设备故障、网络中断、内容争议 → 人工应急 + 内容审核
- **隐私与人工复核**：直播与录播需参与者授权；代码评审结论由人类维护者终审

## S05 场景测试街区（自动驾驶/机器人）
- **定位**：众智园内的合法测试验证街区
- **用户旅程**：企业申请测试路权 → 备案 → 测试运行 → 数据回传 → 安全评估
- **输入数据**：车辆/机器人状态、测试路况、事故记录
- **AI 能力**：测试场景生成、安全监控、事故分析
- **基础设施**：测试环路 1.8km、围栏与监控、数据平台
- **运营主体**：区级测试管理办公室 + 第三方检测机构
- **失败模式**：测试事故 → 立即停测 + 人工调查 + 责任认定
- **隐私与人工复核**：测试全程记录可追溯；涉及行人的场景须先公示并取得同意

## S06 数据要素公共展厅
- **定位**：大钟寺应用仓的数据流通可视化窗口
- **用户旅程**：访客参观 → 了解数据要素流通规则 → 体验合规交易演示
- **输入数据**：脱敏后的流通统计、合规案例
- **AI 能力**：数据可视化、合规问答助手
- **基础设施**：展厅 0.3ha、大屏、演示沙箱
- **运营主体**：数据交易所合作运营
- **失败模式**：演示数据泄露 → 沙箱隔离 + 应急下线
- **隐私与人工复核**：仅展示脱敏统计；参观预约记录 14 天后删除

## S07 AI 教育实验室带
- **定位**：中小学—高校—企业贯通的 AI 教育走廊
- **用户旅程**：学校预约 → 分层课程 → 动手实验 → 成果展示
- **输入数据**：课程资源、实验环境状态、学习成果（脱敏）
- **AI 能力**：个性化学习推荐、实验辅助
- **基础设施**：沿线 6 处教育实验室、算力共享池
- **运营主体**：区教委 + 高校 + 企业联盟
- **失败模式**：算力不足、内容不适龄 → 人工课程审核
- **隐私与人工复核**：未成年人数据严格最小化，家长知情同意；成绩不用于商业用途

## S08 数字孪生城市观测台
- **定位**：众智算塔公共层的城市运行可视化
- **用户旅程**：市民/游客登塔 → 查看城市运行指标 → 参与公共事务反馈
- **输入数据**：城市运行聚合数据（交通、环境、能耗）
- **AI 能力**：城市指标预测、异常预警
- **基础设施**：众智算塔公共层、大屏、算力中心
- **运营主体**：区城运中心
- **失败模式**：数据口径错误 → 标注数据来源与更新时间；预警须人工研判
- **隐私与人工复核**：仅展示聚合数据，不展示个体可识别信息

## S09 AI 健康服务舱（社区嵌入式）
- **定位**：原点社区与银发人群的社区健康服务
- **用户旅程**：居民预约 → 健康自测（血压/体脂等）→ AI 初筛 → 医生复核
- **输入数据**：健康自测数据、居民授权档案
- **AI 能力**：健康风险初筛、异常预警
- **基础设施**：社区健康舱（每社区 1-2 处）、远程问诊终端
- **运营主体**：社区卫生服务中心 + 服务商
- **失败模式**：误判漏判 → 所有 AI 建议均需医生复核，不替代诊疗
- **隐私与人工复核**：健康数据为敏感数据，加密存储、分级授权；提供退出机制与线下人工通道

## S10 智能公交接驳线
- **定位**：轨道站点与园区之间的智能微循环公交
- **用户旅程**：出站 → 手机预约 → 动态调度 → 上车 → 到达
- **输入数据**：预约请求、实时客流、车辆位置
- **AI 能力**：动态排班、客流预测
- **基础设施**：接驳环线（大钟寺/众智园站）、公交站台、调度平台
- **运营主体**：公交集团 + 园区联合运营
- **失败模式**：调度失衡 → 人工调度介入；老年乘客提供电话预约/现场候车兜底
- **隐私与人工复核**：预约数据仅用于调度，行程结束后删除；保留现金/卡等非数字支付通道
