# 开源京张｜评审导读与维护补交附件

把被纪念的百年铁路，转化为持续接收城市议题、公开验证 AI 方案并留下版本记录的开放主干线。

评审首先看一句话：**城市问题先到京张公开验证，AI 先证明，人再决定。** 再看一张总图：一条 Living Mainline、三座 Station Yards、两个公共 Switches 与无限可扩展 Branches。众智园负责 Build，AI 原点负责 Review，大钟寺负责 Merge；三座地标分别是众智编组场、开源零号站与万智交换站。

本案最核心的原创不是一个造型，而是把 `Issue → Branch → Sandbox → Human Review → Merge → Changelog` 同时写进空间、场景和运营。十四张场景卡都必须交付 Model Passport；Merge 只表示进入下一轮专业深化与审查，不代表政府采纳、采购、建设或上线。

所有空间结果来自九层 GeoJSON，核心指标统一在 EPSG:4548 复算。边界为仓库 provisional 几何，可用于正式内容评审、方向性设计和一致性校核，但不是官方红线、法定控制或审批依据；公开场地面积只写约 11.4 平方千米，精确复算值留在机器证据中。官方资料补齐后须整体重算。

## 三项低风险模拟试点协议

三项试点均保持 `concept / simulation`。当前没有真实 Owner、场地许可、预算、采购、保险、数据处理协议、值守排班或实测数据；任何一项缺失都不允许表述为已启动、已部署或已取得绩效。

### 11 京张文化证据导览

- 目标：验证“每条公开事实都可回到来源、未知即显示未知”的导览流程，不评价游客转化或商业效果。
- 模拟输入：已登记且可公开引用的文字来源、五张原创图和合成参观路线；不使用外部照片、真实游客轨迹或人脸/声纹。
- 成功门槛：所有对外事实均绑定有效 source ID；随机抽取的叙事卡可由第二名审校者复现来源；不确定内容明确标为未知。
- 暂停门槛：任一事实缺少来源、来源与表述不一致、出现未清权视觉资产，或无法提供人工讲解等价通道。
- 人工复核：未来的 Scenario Owner、史料编辑、权利复核人与受影响群体代表共同签字；初审者不得处理自己的申诉。
- 退出：撤下对应叙事卡、保留去标识化更正记录、恢复人工/静态导览；不以自动替代来源。
- 外部闸门：档案使用许可、场地展示许可、最终版权与史实审校。

### 14 城市议题路由台

- 目标：验证去标识议题能否按公开规则进入 Branch / Hold，并保留人工改派与申诉，不自动决定公共优先级。
- 模拟输入：合成议题、虚构联系人和固定空间/场景目录；不接真实居民投诉、联系方式、位置轨迹或政务数据。
- 成功门槛：每条模拟议题均可由两名独立复核者解释路由理由；无责任主体或法定条件的议题必须进入 Hold；所有结果可人工改派。
- 暂停门槛：出现个人或敏感字段、系统直接排序高影响公共事项、无法解释路由、无法撤回或人工接管失败。
- 人工复核：未来的议题委员会、Data Steward、领域专业人员和独立申诉人签字；AI 只建议标签和候选 Branch。
- 退出：删除模拟会话数据，保留无个人信息的规则版本和失败案例，恢复纸面/人工受理入口。
- 外部闸门：真实运营主体、数据处理依据、投诉衔接机制、场地与值守安排。

### 10 开放 AI 素养课堂

- 目标：验证固定材料中的来源追踪、模型比较和 Human Override 教学，不评价学习者画像或自动评分效果。
- 模拟输入：仅限成人内部预演、固定公开材料和合成提示；不接未成年人、真实学生档案、摄像头、声纹或自由上传隐私数据。
- 成功门槛：每个练习均能显示来源、限制和人工改写步骤；教师/讲师可完整接管；所有参与者可无惩罚退出。
- 暂停门槛：出现未成年人或敏感数据、生成高风险建议、材料来源不明、无法切换人工教学或参与者无法退出。
- 人工复核：未来的课程 Owner、讲师、来源/版权复核人和受影响群体代表签字。
- 退出：停用模型环节并回到固定材料教学，删除会话内容，仅保留去标识化课程问题清单。
- 外部闸门：课程主体、场地、师资、材料许可、保险与未成年人保护方案；未全部完成前不得扩大。

## 逐资产权利与来源状态

`visual/assets/asset-rights-ledger.json` 为 manifest 中每个交付文件建立唯一记录，登记资产类型、生成/来源、许可、第三方内容和复核状态。文字、原创图表、HTML、GeoJSON 与 PDF 均不包含外部案例图片、Logo、地图瓦片或商业地图截图。PDF 仅嵌入运行环境提供的 STHeiti 字体文档子集，不分发可安装字体文件。最终法律意见仍为人工闸门。

八个国际案例均来自已登记的一手机构页面；`sources.json` 增加 `review_status`、`reviewed_on` 与 `review_note`。当前状态是“投稿内预审完成、外部逐页人工审计待完成”，不表示中央案例库认证、法律可迁移、绩效确认或持续运营确认。任何来源失效或表述超界都应直接撤下对应事实。

## 无障碍预检

静态 HTML 已完成可由代码确定的预检：文档语言、标题、viewport、语义标题层级、图片 `alt`、离线资源、无自动播放/iframe、响应式布局和最小 12px 辅助标签。五张核心图的长描述、短替代文本和读图顺序登记在 `visual/assets/alt-text.json`。

以下项目不得写成已完成：

- A3 与 A0 PDF 当前不是 tagged PDF，屏幕阅读器阅读顺序需人工/专业工具复核。
- A0/A3 实际印刷尺寸、远读可读性、色彩和低视力对比度需打样验证。
- 中文与英文辅助译文的一致性需人工语言复核；旧版 v1 双语兼容警告不等于内容错误。
- 公开展示前需由无障碍体验者完成键盘/读屏/放大/色觉与替代说明复核并签字。

## 当前主分支验证说明
