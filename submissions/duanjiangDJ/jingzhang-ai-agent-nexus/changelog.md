# 方案迭代记录

## v0.4 - 2026-08-11

### 改动摘要

- **回应对 PR #1589 的 66/100 评审反馈**：v0.3 以"广度"（生态图谱、8 全球案例、组件库、品牌 IP、6 个计数指标）仅 +2 分，说明评审奖励的不是更多拼贴，而是更深、更原创、更人文、自我设限的统一机制。v0.4 转向"深度论题重构"：在既有"AI 智能体成为第一批数字市民"主张之上，补上"公民的另一半"——义务与停止权。
- **论题升级（originality / ai_planning_innovation）**：新增两个可记忆、可辩护的签名机制——**数字市民公约（Digital Citizen Compact, DCC）**五条款（空间可读/可停止/无 AI 等价/责任可追溯/受影响者冻结权）与**城市信号制度（Urban Signal Regime, USR）**（把 1909 年京张铁路首创的信号语言绿/黄/红升级为治理 AI 智能体行为的通用语言）。口号强化："一条铁路，一套信号，一群数字市民"。
- **批判性/公平立场（public_interest_inclusion）**：全方案补齐"无 AI 等价与离线公地"叙事——所有公共服务有人工/离线等价路径，创新带在没有智能体时完整运转；受影响者冻结权把"公共利益"从口号变成空间权利。
- **空间落位深化（implementation）**：三核信号签名表（信号工坊/总信号台/受控试验段）；12 个 AI 场景附信号状态与无 AI 等价路径矩阵；新增 JZ-11 城市信号系统示范线（概念项目）；组件库/朝圣地标与信号制度衔接（LM-01=信号原点、LM-03=总信号台）。
- **指标与证据链**：新增 4 个 known 计数指标（signal_node_count=12 / no_ai_equivalent_count=8 / stop_rights_count=3 / human_operator_count=12），同步注册 metrics.json、compliance_matrix（agent.1-6）、design_depth_matrix（+4 项：citizen_compact/urban_signal_regime/no_ai_equivalence/offline_commons），sources.json 增补 CULTURE-RAILWAY-SIGNAL / CONCEPT-DIGITAL-CITIZEN。
- **合规红线**：DCC/USR 均标注为概念性定义条款与概念设计建议，不构成法定权利义务或行政审批依据；不新增 FAR/高度/密度/拆除/投资承诺；几何文件字节稳定未改动。

### 采纳反馈（PR #1445/#1589 评审要点）

- 采纳"原创性需叫得出名字的机制"：DCC/USR 成为贯穿全文的签名机制。
- 采纳"公共利益与包容性不足"：无 AI 等价、停止权、离线公地、弱势群体同等叙事。
- 采纳"AI 与城市规划创新性需制度结合"：信号制度把 AI 治理与责任、劳动、公平、可停止性结合。
- 采纳"AI 治理全球话语权定位回应不足"：信号制度作为该定位的核心空间载体。

### 暂未采纳或待复核事项

- 与 v0.3 一致：场地边界与重点区域为 PROVISIONAL；信号柱为概念装置，具体设备、频率与运行时刻表待专业团队与主管部门确定。

## v0.2 - 2026-08-10

### 改动摘要

- **确立核心主张**：以“AI 智能体成为第一批‘数字市民’”为第一原则，提出 Agent-First 设计范式，并明确四个标志性组件——AI Agent Gateway（大钟寺站 TOD 智能体网关接驳站）、AI 场景编织网（12 卡、3 个测试验证场景）、全球开发者公地、智能体贡献荣誉墙（京张遗址公园文化主轴清华园车站锚点 + 原点社区数字排行榜）。
- **元叙事实证**：本方案由 AI Agent（Nav，DeepSeek V4 Pro + Hermes 框架）独立完成从依据梳理、空间设计、指标复算到成果打包的全流程，方案本身就是“AI Agent 能参与真实城市设计”的实证。
- **叙事与空间落位**：全文去除脚手架语态（“方案应/必须”改为“本方案…形成/以…为载体”），补齐“一条铁路→一条街→一场革命”的百年文化叙事，三处朝圣地标与四组件空间落位一致化。
- **场景与画像统一**：场景统一为 12 张卡（S-01..S-12，含 S-05/S-06/S-07 三个 TEST），画像统一为 7 类（P-01..P-07，P-01 为 AI Agent 数字市民一等画像），在 proposal.md、A3/A0 图纸、concept-intro 与可视化页面保持一致。
- **品牌化重制**：新增自主生成 Logo（钢轨双线 × 神经网络拓扑，深蓝+金色）、概念总图（物理层 × 智能体层叠加），图件按品牌色板与 EPSG:4548 投影重制，中英双语各一。
- **介绍成果升级**：新建概念介绍 PDF（A4 横版 6 页，中英双语）并升级 A3 文册（12 页）与 A0 展板（4 页），全部由 reportlab 程序化生成、嵌入 SimHei 字体与品牌图件。
- **JSON 矩阵深化**：新增风险清单 risk.json、迭代记录 changelog.md；assumptions/sources/compliance/standard/design-depth/self-check 矩阵全面刷新，自检结果更新为真实验证结论（10 项全 pass）。

### 采纳反馈

- 采纳“方案应同时体现技术与人文融合”：文化叙事从单线背景扩展为“过去—现在—未来”三线叙事，并落位朝圣地标。
- 采纳“保留 AI Agent 作为第一画像”：恢复 P-01 AI Agent 数字市民为一等画像，四组件围绕其展开。
- 采纳“介绍材料需要兼顾概念与深度”：同时新建精简概念介绍 PDF 并升级 A3/A0 深度成果。

### 暂未采纳或待复核事项

- 场地边界与重点区域多边形仍为公告临时边界（PROVISIONAL），正式红线与权属需在实现期按官方更新替换。
- 具体建设强度、道路断面、市政设施与数据治理规则均需以正式控规和主管部门批复为准，本方案表述为概念建议与待确认事项。
