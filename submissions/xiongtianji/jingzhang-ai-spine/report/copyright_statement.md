## Font license (added in v2 revision)

To fix missing CJK glyphs ("tofu boxes") in the rendered HTML/PDF, this package embeds the open-source font **Noto Sans SC** (Simplified Chinese) as a base64 woff2 subset via `@font-face`, with no external font fetch.

- **Typeface:** Noto Sans SC (weights 400 / 700)
- **Author / Source:** Google Fonts / Noto project (https://github.com/notofonts/noto-cjk, distributed via @fontsource/noto-sans-sc)

- **Embedding basis:** The font is embedded subsetted and unmodified except subsetting; OFL 1.1 §1 permits embedding (including subsets) in documents and redistributing the subset. The full SIL Open Font License 1.1 text and copyright notice ship with the original font package and are incorporated by reference (https://openfontlicense.org).
- **Usage:** Used only for on-screen/text rendering of Chinese (and Latin) in `report/proposal.html`, `report/proposal.en.html`, `visual/index.html`, `visual/index.en.html`, and the A3/A0 PDFs (reportlab CID font `STSong-Light` is used for PDF body text, also an Adobe-standard CJK font; no separate embedding needed there).
