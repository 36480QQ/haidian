# Asset Rights and Font Licence

## Submission assets

- `cover-concept.png`: participant-prompted conceptual image generated with the OpenAI built-in image-generation tool on 2026-08-14; no real site or third-party image is represented.
- `cover.webp`: local crop, resize and conceptual-status label derived from `cover-concept.png`.
- `logo.svg`, five bilingual figure pairs, visual HTML and four PDFs: generated locally from participant-authored code and submission data.
- External webpages, standards and research graphics are not copied into the package.

## Noto Sans SC

Build dependency: local `NotoSansSC-VF.ttf`. The full font program is not committed; figures contain rasterised glyphs, PDFs contain embedded subsets, and the four offline HTML pages share a page-character WOFF2 subset embedded as a data URI in `visual/assets/steady-field-noto-sans-sc.css`.
