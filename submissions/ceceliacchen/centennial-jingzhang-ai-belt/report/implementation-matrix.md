## 治理原则
- **分期推进**：一期打样（绿脉 + 原点 + 开源发布厅），二期实测（中试 / 评测 / 沙盒 / 治理廊），三期放大（数据要素 / 小月河 / 外围联动）。
- **责任主体一律拟议**：任何主体出现时标注「（拟议）」，不主张既有合作。
- **经费一律概念**：仅为来源方向，不构成预算或承诺。
- **KPI 一律方向性**：以 `metrics.json` 的 `directional_estimate` / `parametric_demonstration` 口径呈现，不表述为实测。
- **合规前置**：凡涉数据 / 医疗 / 治理，默认人工复核与不出域；任何荣誉不参与商业排名或招投标加分。

> 本矩阵为概念级交付，须经资质团队与官方资料复核后方可作为实施依据。
