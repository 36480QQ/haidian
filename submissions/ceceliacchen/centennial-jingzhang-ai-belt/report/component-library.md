# 公共空间组件库 · Public-Space Component Library

> 概念级可复制模块集（conceptual, reusable）。各模块可沿京张绿脉组合落点；隐私等级遵循「公开—授权—脱敏—人工复核」四级。详见 `component-library.json`。

## 组合原则
- **服务密度**：以 C-01 为基底，每 400–600 m 步行圈至少 1 处；C-03 优先布置于轨道站点与公园主入口。
- **实测锚点**：C-02 仅与 NODE-01/02/03（产业实测）共线，数据不出域。
- **治理可见**：C-04 与 NODE-12 治理廊同址，公示屏对接治理廊合规态势。
- **文化连续**：C-05 串联铁路遗存展示段，形成「脉」的叙事骨架。
- **包容优先**：C-03 / C-07 为必配项，体现无障碍与全龄友好。

> 本组件库为概念级交付，须经资质团队与官方资料复核后深化为可建设图纸。
