## Execution receipts (v1.11)｜执行回执（v1.11）

`visual/assets/execution-receipts.json` is a machine-generated record of three headless-Chromium
runs driving this package's own interactive protocol page, written by the re-runnable script
declared in `agent.json`. It contains only event text observed from the package's own files,
hash-chained per event and bound to artifact sha256 digests. It is participant self-test
evidence — not field evidence, not a safety proof, and not an approval of any operation — and
contains no personal data, no third-party content and no external network material.

`visual/assets/execution-receipts.json` 为机器生成的执行记录：无头 Chromium 驱动本包自身交互
协议页的三次运行，由可重跑脚本产出。文件仅含从本包自身文件观测到的事件文本，逐事件哈希链并
绑定产物 sha256。属参赛者自测证据——非现场证据、非安全证明、非任何运营批准——不含个人数据、
第三方内容或任何外部网络素材。

## Embedded display font (v1.13)｜内嵌显示字体（v1.13）

The four HTML display surfaces (`report/proposal.html`, `report/proposal.zh.html`,
`visual/index.html`, `visual/index.zh.html`) embed glyph subsets of **Noto Sans SC**
(Regular and Bold), © Google and contributors, used under the **SIL Open Font License 1.1**.
The subsets cover only the characters actually used by these pages, are generated by a
re-runnable script (fonttools `pyftsubset`, source `github.com/notofonts/noto-cjk`
SubsetOTF/SC, obtained 2026-08-24), and are embedded as data-URI web fonts so Chinese text
renders identically on machines without system CJK fonts. OFL 1.1 permits subsetting and
embedding; the subsets are derived works distributed under the same licence. The font is a
display-layer asset only and carries no design claim or data evidence.

四个 HTML 展示面（`report/proposal.html`、`report/proposal.zh.html`、`visual/index.html`、
`visual/index.zh.html`）内嵌 **思源黑体 Noto Sans SC**（Regular 与 Bold）的字形子集，
© Google 及贡献者，依 **SIL Open Font License 1.1** 使用。子集仅覆盖页面实际用到的字符，
